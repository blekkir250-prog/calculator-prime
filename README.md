# Price Calculator Widget

Простой, адаптивный и интерактивный виджет для динамического расчета стоимости товара или услуги в режиме реального времени. 

Виджет легко кастомизируется и может быть интегрирован на любой сайт (например, карточку товара в интернет-магазине или лендинг).

## 🚀 Демонстрация возможностей
* **Динамический расчет**: Итоговая стоимость пересчитывается мгновенно при смене базовой модели или переключении чекбоксов с дополнительными опциями.
* **Форматирование валюты**: Числа автоматически форматируются под стандарты локали `ru-RU` (с разделением тысяч и добавлением знака ₽).
* **Адаптивный дизайн**: Корректно отображается как на мониторах, так и на мобильных устройствах.
* **Поддержка темной темы**: Автоматически адаптируется под системные настройки пользователя (светлая/темная тема устройства) благодаря использованию медиа-запроса `prefers-color-scheme`.

## 🛠️ Стек технологий
* **HTML5** — семантическая структура виджета.
* **CSS3 (Custom Properties / CSS Variables)** — темизация, стилизация элементов управления и встроенная адаптивная темная тема.
* **Vanilla JavaScript** — логика калькуляции без использования сторонних библиотек и фреймворков.

## 📦 Структура проекта
* `index.html` — разметка формы калькулятора, селекта выбора модели и чекбоксов.
* `style.css` — стили виджета, переменные для кастомизации палитры, адаптивная верстка под мобильные экраны и темную тему.
* `script.js` — скрипт инициализации событий обработки изменений (`change`) и калькуляции цен.

## ⚙️ Как использовать и кастомизировать

### Переменные стилей
Вы можете легко изменить цветовую схему виджета под дизайн вашего основного сайта, отредактировав CSS-переменные в блоке `:root` файла `style.css`:
```css
:root {
    --primary-color: #2563eb; /* Основной акцентный цвет (кнопки, чекбоксы, цена) */
    --text-main: #1f2937;     /* Цвет основного текста */
    --bg-card: #ffffff;       /* Фон карточки виджета */
    --radius: 12px;           /* Скругление углов виджета */
}
```
